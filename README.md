# Agent Factory Studio

Private Agent Factoryハンズオンを、ブラウザで進めるビジュアルノベル形式の学習ガイドです。

公開サイト: https://kutsushitaneko.github.io/paf-livelabs-visual-novel/

## このリポジトリについて

この公開リポジトリには、ブラウザへ配信する静的ファイルだけを置きます。ソース、シナリオの編集履歴、画像台帳、テストは非公開の管理リポジトリにあり、検査に合格した成果物が`gh-pages`ブランチへ自動配信されます。

`gh-pages`ブランチは自動生成物です。直接編集しないでください。

## 注意

このサイトは非公式の教育用ガイドです。OracleまたはGitHubが提供・保証する公式コンテンツではありません。実際の操作では、所属組織のルールと現行のOracle公式ドキュメントを優先してください。
